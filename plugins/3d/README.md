# 3D

Transforme une description en maillage GLB avec Shap-E. Dans Réglages → Modèles locaux, installe le pack Shap-E. Sillune prépare un environnement isolé pour ce moteur et télécharge Python 3.12 via uv si nécessaire. Le GPU Intel fonctionne avec un PyTorch XPU déjà disponible et le moteur peut utiliser le CPU.
