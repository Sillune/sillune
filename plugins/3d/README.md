# 3D

Installe **TRELLIS.2** dans **Réglages → Modèles locaux**. Dans le mode **3D**, joins un PNG ou un JPEG avec le bouton **+** ou décris un objet. Une description passe d’abord par Z-Image Turbo, FLUX.2 klein ou SDXS selon les modèles déjà installés.

Le pack 512 utilise Vulkan pour le détourage BiRefNet, la reconstruction du maillage et la génération des textures. Le GLB contient un atlas de 1 024 px. Il s’ouvre dans l’aperçu rotatif de Sillune et peut être exporté.

Les poids sont téléchargés à la demande. Consulte les conditions de chaque composant. [TRELLIS.2](https://huggingface.co/microsoft/TRELLIS.2-4B), [poids GGUF](https://huggingface.co/ilintar/trellis2-gguf), [moteur trellis.cpp](https://github.com/pwilkin/trellis.cpp), [DINOv3](https://huggingface.co/facebook/dinov3-vitl16-pretrain-lvd1689m), [BiRefNet](https://huggingface.co/ZhengPeng7/BiRefNet).
