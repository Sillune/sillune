# 3D

Transforme une description en maillage GLB avec Shap-E. Dans Réglages → Modèles locaux, installe le pack Shap-E après avoir installé Python 3.12 sous Windows. Sillune prépare un environnement Python séparé pour ce moteur. Le GPU Intel fonctionne avec un PyTorch XPU déjà disponible et le moteur peut utiliser le CPU.
